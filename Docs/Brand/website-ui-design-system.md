# Indian One Anime × Dubkami — Website UI Design System

A visual and digital experience guide for building the Indian One Anime website and Dubkami app promotion experience. The direction is premium, cinematic, anime-inspired, mobile-friendly, and scalable.

## Core Brand Message

> **Discover anime. Explore new worlds. Find your next favorite story.**

- **Indian One Anime** is the platform.
- **Dubkami** is the mobile experience.
- **Anime** is the universe.

## 1. Visual Direction

### Design Personality

- Premium and cinematic
- Dark anime-inspired interface
- Gold-accented brand highlights
- High-contrast content cards
- Mobile-first and app-ready
- Energetic, immersive, and fan-focused

### Visual Mood

Use deep backgrounds, gold highlights, glowing accents, anime poster cards, rounded sections, soft shadows, and bold CTAs to create a premium streaming-platform feel.

## 3. Typography Hierarchy

| Style | Suggested Size | Weight | Usage |
| --- | --- | --- | --- |
| Display / Hero | 56–72px desktop, 36–44px mobile | 800 | Main hero headline |
| H1 | 48–56px desktop, 32–40px mobile | 800 | Page title |
| H2 | 36–44px desktop, 28–32px mobile | 700 | Section title |
| H3 | 24–30px | 700 | Card groups and subsection titles |
| Body Large | 18–20px | 400–500 | Hero and section intros |
| Body | 16px | 400 | Standard paragraphs |
| Label / CTA | 14–16px | 700 | Buttons, labels, tags |

### Font Direction

Use a bold modern sans-serif for interface text and a premium serif or display font only for selective logo-style hero accents. Keep long-form copy highly readable.

## 9. Responsive Design Notes

- Design mobile-first and scale up for tablet and desktop.
- Keep hero CTAs stacked on small screens and inline on larger screens.
- Use 2-column card grids on tablets and 4–6 columns on desktop depending on poster size.
- Keep text line lengths short for readability on dark backgrounds.
- Prioritize performance: compress poster images and lazy-load media-heavy sections.

## 10. Brand Do’s and Don’ts

### Do

- Use accurate feature claims.
- Keep anime discovery simple and fan-friendly.
- Use gold accents consistently.
- Pair Indian One Anime with Dubkami as platform + app.
- Keep copy premium, clear, and energetic.

### Don’t

- Promote upload, download, AI, or community features unless they are live.
- Overcrowd the hero section with too many messages.
- Use low-contrast text on dark backgrounds.
- Mix too many font styles.
- Make Dubkami compete with Indian One Anime; Dubkami should support the main platform identity.

## 11. Entertainment Streaming Upgrade Modules

Use the same design system to scale the brand from a landing page into a fuller streaming-focused experience.

### Website Modules

- **Hero carousel** for flagship anime and campaign banners
- **Trending rail** with ranked or highlighted poster cards
- **Category shelves** for action, fantasy, romance, comedy, and dubbed picks
- **Anime detail layout** with poster, synopsis, badges, episode status, and related titles
- **Search and filter bar** with mobile-friendly chips and clear empty states

### App Modules

- **App home feed** mirroring website sections for instant familiarity
- **Continue exploring row** for quick return to in-progress discovery
- **Compact detail screen** with strong CTA hierarchy and poster-first layout
- **Download CTA panels** that keep Dubkami visible without overwhelming content

## 12. Upgrade Delivery Notes

- Prioritize responsive components that work on both website and mobile surfaces.
- Keep CTA language consistent: **Explore Anime**, **Watch Now**, **Get Dubkami App**.
- Use modular cards and section blocks so future streaming features can be added without redesigning the whole experience.
- Treat app and website as one entertainment ecosystem with shared visual tokens and content structure.
